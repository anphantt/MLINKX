Official implementation of **"MLINKX Multiview Graph Learning for Brain Cognitive Disease Detection"**.

## Requirements

```bash
pip install -r requirements.txt
```
## Dataset

The CAUEEG dataset is not redistributed in this repository.

To request access to the full CAUEEG dataset, please follow the instructions provided by the dataset authors:

https://github.com/ipis-mjkim/caueeg-dataset

## Usage

Run the main training script:

```bash
python train.py
```
